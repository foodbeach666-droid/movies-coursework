О приложении «Учет Фильмов»

Данный сервис представляет собой курсовой проект, разработанный для учета и управления каталогом фильмов, актерским составом и финансовыми показателями (кассовыми сборами и гонорарами).

Функциональные возможности:

  • Управление каталогом фильмов (добавление, редактирование, удаление).
  • Ведение базы данных актеров и привязка их к соответствующим кинокартинам.
  • Расчет суммарных и средних кассовых сборов.
  • Разграничение прав доступа (Пользователь / Администратор).

Стек технологий:

  • Backend: Java 17, Spring Boot, Spring Data JPA, Spring Security
  • Frontend: Thymeleaf, HTML5, CSS3, Bootstrap 5
  • База данных: H2 Database / MySQL
